AIM'S AI — simple static website

Files:
- index.html: complete responsive one-page website

Publish for free with GitHub Pages:
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository named aims-ai-site (or another name).
3. Upload index.html to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. The site address will appear on the Pages settings screen.

Important:
- This is a starter website, not proof that a startup qualifies for any offer.
- The page deliberately says the project is early-stage and does not claim users, funding, or features that do not exist.
- A GitHub Pages address is not a custom domain and does not provide a matching business email.
